PORTFOLIO LORENZO — INSTRUCCIONES

1. Abrí la carpeta "lorenzo-portfolio" con Visual Studio Code.
2. Abrí index.html.
3. Para verlo como sitio local, podés instalar la extensión "Live Server" y usar "Open with Live Server".
   También podés abrir index.html directamente en el navegador.
4. No cambies la estructura de la carpeta images salvo que también actualices las rutas en index.html.
5. Para publicarlo luego, esta carpeta es compatible con hosting estático (por ejemplo GitHub Pages o Netlify).

Archivos:
- index.html: contenido y estructura
- style.css: diseño responsive
- script.js: menú móvil, año y galería ampliable
- images/: fotos optimizadas en WebP
